# Change Log

All notable changes to the "remote-health" extension will be documented in this file.

## [Unreleased]

- Added a theme-aware status bar summary and detailed metrics tooltip.
- Added an isolated, authenticated metrics agent with explicit scope reporting.
- Added CPU, memory, battery, temperature, network, disk, load, and uptime metrics.
- Added debounced alerts with hysteresis and configurable thresholds.
- Added a mounted Unix-socket bridge for host metrics from a dev container.
